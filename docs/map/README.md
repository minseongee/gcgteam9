# 캠퍼스 지도 이미지 (`img/campus-map.png`)

지도 화면(`map.html`)의 배경 지도입니다. 카카오맵 캡처 대신 **OpenStreetMap(OSM) 데이터로 직접 그렸습니다.**

- 캡처 이미지는 화면 글자·버튼이 같이 찍히고, 모서리 위도·경도를 손으로 맞춰야 해서 핀이 어긋나기 쉽습니다.
- 직접 그리면 모서리 좌표가 정확히 정해져 있어 핀 위치가 실제와 맞고, 사이트 색(갈색·베이지)에 맞출 수 있습니다.
- OSM 데이터는 자유롭게 쓸 수 있고, 대신 이미지 오른쪽 아래에 `© OpenStreetMap contributors`를 표시해야 합니다.

## 범위

| 모서리 | 위도 | 경도 |
| --- | --- | --- |
| 왼쪽 위 | 35.8975 | 128.6020 |
| 오른쪽 아래 | 35.8835 | 128.6185 |

경북대 대구캠퍼스 전체 + 북문·정문·서문 바깥 골목 조금. 이 값은 `js/data.js`의 `MAP_BOUNDS`와 같아야 합니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `campus-osm.txt` | OSM에서 받은 건물·길·물·운동장 모양 (그림 좌표 1200 × 1257로 바꾸고 단순화한 값) |
| `render-map.py` | 위 데이터로 이미지를 그리는 파이썬 스크립트 (Pillow, Noto Sans CJK 글꼴 필요) |

`campus-osm.txt` 한 줄 = 도형 하나. 첫 글자가 종류(`C` 캠퍼스 경계, `B` 건물, `R1`~`R3` 큰 길~작은 길, `F` 보행로, `W` 물, `S` 운동장, `G` 녹지)이고, 뒤는 점 좌표입니다(첫 점은 절대값, 다음부터는 앞 점과의 차이).

## 다시 그리기

```bash
python3 docs/map/render-map.py docs/map/campus-osm.txt img/campus-map.png
```

건물 이름 표시는 `render-map.py`의 `LABELS`, 문 이름은 `GATES`에서 고칩니다. 출력은 1920 × 2011 px이고, 화면에서는 `.map-canvas` 폭 900px로 보입니다.
