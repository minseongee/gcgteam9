## 정리 규칙

1. **메뉴 타입 5개로 분류**
   - 커피: 필터 커피, 에스프레소 계열(아메리카노·라떼·모카·마키아또), 크림 커피, 콜드브루, 커피가 들어간 시그니처 라떼
   - 논커피 라떼: 커피 없는 라떼·밀크티·초코·딸기라떼·곡물/고구마/토피넛 라떼, 스팀밀크
   - 차: 티·차·아이스티, 아샷추(아이스티 바탕), 뱅쇼
   - 에이드·스무디: 에이드, 스무디, 쉐이크, 프라페·프라푸치노·할리치노·퐁크러쉬, 주스, 샹그리아, 얼박사
   - 디저트: 쿠키
2. **`/`로 묶인 메뉴는 각각 따로 나눴습니다.** 같은 가격이면 같은 값, 가격도 `/`로 나뉘어 있으면 순서대로 맞췄습니다.
   - 예: `딸기 / 망고 / 치즈 / 요거트: 4,300원` → 스무디 4개, `카라멜마끼아또 / 카페모카: 3,700원 / 3,900원` → 각각
   - 단, 오리지널/디카페인, 사이즈처럼 '같은 음료의 선택'은 한 메뉴로 두고 옵션에 적었습니다.
3. **카페 공통 추가 옵션**(샷 추가, 디카페인, 사이즈업, 우유 변경 등)은 해당하는 메뉴의 옵션 칸에 적었습니다.
4. **겹친 메뉴는 한 번만**: 빅핸즈의 상하목장라떼·바닐라크림라떼(시그니처와 커피 목록에 둘 다 있음)
5. **메뉴가 아닌 줄은 뺐습니다**: `후원 1,000원`, `image_004338.png`, 추가 옵션 줄
6. **이름 앞 꾸밈말 정리**: `수제청) 딸기라떼` → `수제청 딸기라떼`, `과육듬뿍) 리얼딸기스무디` → `리얼딸기스무디`(옵션: 과육 듬뿍), `빅)얼박사` → `얼박사`, 필터 커피는 이름 뒤에 `(필터)`
